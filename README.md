# One Line, Big Laugh

Entry for the [make.fun bounty "One Line, Big Laugh"](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857).

A program that writes a single funny line to `/output/entry.txt`:

> My neighbour's rooster crows at 3:12 sharp every morning, because even the rooster is afraid of being late for work.

## Run

```sh
python3 -P -s main.py
```

Python 3.13, standard library only.
